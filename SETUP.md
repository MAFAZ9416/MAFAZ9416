## One required setup for real analytics

The five SVG cards are included now as clearly labelled preview assets so the README has no missing image paths immediately. To replace them with your actual account data:

1. Create a fine-grained GitHub Personal Access Token for your account.
2. Give it access to the `MAFAZ9416` repository, with **Contents: Read and write** and **Metadata: Read-only**.
3. In the repository, open **Settings → Secrets and variables → Actions → New repository secret**.
4. Name it exactly `SUMMARY_GITHUB_TOKEN` and paste the token as its value. Never put the token in a file or README.
5. Open **Actions → Update GitHub Profile Statistics → Run workflow**.
6. When it succeeds, the generator replaces the preview cards with generated profile-summary SVGs in `profile-summary-card-output/github_dark/`.

## Generate the real contribution snake

1. Open **Actions → Generate Contribution Snake → Run workflow**.
2. The workflow reads your public GitHub contribution calendar and commits the generated SVGs into `assets/` on `main`.
3. When the run succeeds, it replaces the included preview SVGs with the real contribution animation.

The snake workflow uses the repository's built-in `GITHUB_TOKEN` with `contents: write`; no additional secret is required for it.
