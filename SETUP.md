# MAFAZ9416 GitHub Profile — Setup

This folder is intended for the profile repository named **MAFAZ9416/MAFAZ9416**.

## Included files

- `README.md` — profile layout and image references.
- `profile-banner.png` — your supplied banner.
- `.github/workflows/github-stats.yml` — generates local summary-card SVGs.
- `.github/workflows/snake.yml` — generates contribution snake SVGs and publishes them to the `output` branch.

## Upload

1. Extract this ZIP.
2. Open your GitHub repository: https://github.com/MAFAZ9416/MAFAZ9416
3. Upload the contents of this folder to the repository root. Keep the `.github/workflows/` folder structure.
4. Commit to the `main` branch.

## Enable GitHub summary cards

The summary-card workflow needs a personal access token stored as a repository secret:

1. Create a GitHub personal access token with access to read public repositories for your account.
2. In the repository, open **Settings → Secrets and variables → Actions**.
3. Add a repository secret named exactly `SUMMARY_GITHUB_TOKEN`.
4. Paste the token as its value. Never paste a token into README or workflow code.
5. Open **Actions**, select **Update GitHub Profile Analytics**, and choose **Run workflow**.

The generated files will be committed to:
`profile-summary-card-output/github_dark/`

## Enable contribution snake

1. Open **Settings → Actions → General** in the repository.
2. Under **Workflow permissions**, ensure workflows are allowed to have write access to the repository if required by your organization settings. The workflow declares `contents: write`.
3. Open **Actions → Generate Contribution Snake → Run workflow**.
4. After it succeeds, GitHub will create/update the `output` branch with the SVG files.

## Important

- The analytics SVGs are generated by the workflow; they are not included in this ZIP yet.
- The contribution snake SVGs are generated by its workflow and stored on the `output` branch.
- GitHub achievements are earned and displayed by GitHub itself. The README links to your real achievements page rather than displaying invented trophies.
- GitHub Actions scheduled workflows can be delayed by GitHub. Use **Run workflow** for the first generation.
- Do not commit personal access tokens or other secrets.
